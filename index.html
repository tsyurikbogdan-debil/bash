Основи GNU/Linux та Git

Практичний посібник з командного рядка, BASH та системи контролю версій

1. Коротка інформація про ОС GNU/Linux

GNU/Linux — це вільна, відкрита та кросплатформна операційна система, побудована на основі ядра Linux та системних утиліт проєкту GNU. Вона є стандартом для серверів, хмарних обчислень, суперкомп'ютерів та інструментом №1 для розробників.

Безпека

Суворе розмежування прав доступу та відкритий сирцевий код роблять систему стійкою до загроз.

Продуктивність

Ефективне використання ресурсів дозволяє працювати як на слабких пристроях, так і на потужних серверах.

Гнучкість

Можливість повністю налаштувати кожен аспект системи: від ядра до графічної оболонки.

3. Приклади команд роботи в Linux CLI

pwd

Виводить повний шлях до поточного робочого каталогу.

echo

Виводить рядок тексту у консоль або перенаправляє його у файл.

ls

Відображає вміст каталогу (наприклад, ls -la).

cd

Змінює поточний каталог (наприклад, cd /var/log).

touch

Створює новий порожній файл або оновлює часову мітку.

mkdir

Створює новий каталог (наприклад, mkdir new_folder).

cp

Копіює файли або каталоги (наприклад, cp -r dir1 dir2).

mv

Переміщує або перейменовує файли та папки.

rm

Видаляє файли або каталоги (наприклад, rm -rf folder).

history

Показує список раніше виконаних команд у терміналі.

4. BASH-скрипт: Авторизація в системі

Вихідний код BASH-скрипту для перевірки облікових даних у текстовому режимі:

#!/bin/bash

# Налаштування правильних даних
CORRECT_USER="admin"
CORRECT_PASS="secret123"

echo "=== Система авторизації GNU/Linux ==="

read -p "Логін: " username
read -sp "Пароль: " password
echo ""

if [ "$username" == "$CORRECT_USER" ] && [ "$password" == "$CORRECT_PASS" ]; then
    echo "Успішна авторизація! Ласкаво просимо, $username."
else
    echo "Помилка: Невірний логін або пароль."
    exit 1
fi
