Основи GNU/Linux та Git

Навчальна сторінка з опрацювання теми

1. Коротка інформація про ОС GNU/Linux

GNU/Linux — це сімейство вільних та відкритих операційних систем, побудованих на основі ядра Linux та набору базових утиліт від проєкту GNU. Завдяки високій стабільності, безпеці та гнучкості налаштувань, GNU/Linux широко використовується на серверах, суперкомп'ютерах, хмарних платформах, вбудованих пристроях (включаючи Android), а також на робочих станціях розробників.

2. Популярні дистрибутиви Linux

  • Ubuntu — один із найпопулярніших дистрибутивів для початківців та серверів на базі Debian.
  • Debian — відомий своєю стабільністю та суворим дотриманням принципів вільного ПЗ.
  • Fedora — дистрибутив, що швидко впроваджує нові технології, підтримується Red Hat.
  • Arch Linux — мінімалістичний дистрибутив за принципом «KISS» (Keep It Simple, Stupid) із системою оновлень Rolling Release.
  • Linux Mint — зручний дистрибутив для щоденного використання на базі Ubuntu зі звичним інтерфейсом.
  • CentOS / AlmaLinux / Rocky Linux — стабільні корпоративні дистрибутиви, сумісні з RHEL.

3. Приклади команд роботи в Linux CLI

Команда Опис Приклад використання
pwd Виводить поточний робочий каталог pwd
echo Виводить текст у консоль або файл echo "Hello World"
ls Відображає вміст каталогу ls -la
cd Змінює поточний каталог cd /var/log
touch Створює порожній файл або оновлює час touch file.txt
mkdir Створює новий каталог mkdir my_folder
cp Копіює файли або каталоги cp file.txt /backup/
mv Переміщує або перейменовує файли mv old.txt new.txt
rm Видаляє файли або каталоги rm -rf my_folder
history Показує історію виконаних команд history

4. BASH-скрипт: Імітація авторизації в системі

Нижче наведено скрипт, який запрошує логін та пароль у текстовому режимі:

#!/bin/bash

# Налаштування правильних облікових даних
CORRECT_USER="admin"
CORRECT_PASS="secret123"

echo "=== Система авторизації GNU/Linux ==="

# Запит логіна
read -p "Логін: " username

# Запит пароля (приховане введення)
read -sp "Пароль: " password
echo ""

# Перевірка авторизації
if [ "$username" == "$CORRECT_USER" ] && [ "$password" == "$CORRECT_PASS" ]; then
    echo "Успішна авторизація! Ласкаво просимо, $username."
else
    echo "Помилка: Невірний логін або пароль."
    exit 1
fi
