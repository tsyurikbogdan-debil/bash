# Система контролю версій Git

**Git** — це розподілена система контролю версій, яка дозволяє відстежувати зміни у файлах та ефективно організовувати командну або індивідуальну розробку.

---

## Основний процес роботи (Workflow)

1. **Working Directory** — робочий каталог з файлами проекту.
2. **Staging Area (Index)** — область підготовки файлів для включення у наступний коміт.
3. **Repository** — збережена база даних із повною історією змін.

---

## Головні команди

### 1. Конфігурація та створення
* `git config --global user.name "Ваше Ім'я"` — налаштування імені користувача.
* `git config --global user.email "email@example.com"` — налаштування електронної пошти.
* `git init` — створення нового репозиторію в поточній папці.

### 2. Управління змінами
* `git status` — перевірка стану файлів у робочому каталозі.
* `git add index.html` — додавання конкретного файла до індексу.
* `git add .` — додавання усіх змінених файлів до індексу.
* `git commit -m "Опис змін"` — фіксація доданих змін із коментарем.

### 3. Віддалені репозиторії (GitHub)
* `git remote add origin <URL_РЕПОЗИТОРІЮ>` — прив'язка локального репозиторію до GitHub.
* `git branch -M main` — перейменування головної гілки на `main`.
* `git push -u origin main` — відправка комітів у віддалений репозиторій.
* `git pull` — отримання та об'єднання змін з віддаленого репозиторію.
