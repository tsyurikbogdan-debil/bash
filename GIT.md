# Основи роботи з системою контролю версій Git

**Git** — це розподілена система контролю версій, яка дозволяє відстежувати зміни у файлах та ефективно співпрацювати над проєктами.

---

## Основні команди Git

### 1. Ініціалізація та налаштування
* `git init` — створення нового репозиторію Git у поточній папці.
* `git config --global user.name "Ваше Ім'я"` — налаштування імені автора.
* `git config --global user.email "email@example.com"` — налаштування електронної пошти.

### 2. Робота зі змінами
* `git status` — перевірка стану робочого каталогу та відстежуваних файлів.
* `git add <file>` — додавання файла до індексу (Staging Area).
* `git add .` — додавання всіх змінених файлів до індексу.
* `git commit -m "Коментар до коміту"` — фіксація збережених змін із повідомленням.

### 3. Віддалені репозиторії (GitHub)
* `git remote add origin <URL_репозиторію>` — зв'язування локального репозиторію з віддаленим.
* `git push -u origin main` — відправка комітів у віддалений репозиторій.
* `git pull` — отримання та об'єднання останніх змін із віддаленого репозиторію.
