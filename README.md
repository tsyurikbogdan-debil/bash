Навчальний проєкт з опрацювання теми операційної системи GNU/Linux, основних команд CLI, BASH-скриптів та роботи з системою контролю версій Git.

## 🔗 Посилання на матеріали:
* 📄 **Документація по Git:** [Переглянути GIT.md](./GIT.md)
* 🌐 **Веб-сторінка на GitHub Pages:** `https://USERNAME.github.io/REPOSITORY-NAME/` *(Замініть на своє посилання)*

## 📂 Структура репозиторію:
* `index.html` — Головна сторінка з теорією та емулятором.
* `styles.css` — Файл стилів оформлення.
* `script.js` — Логіка інтерактивного BASH-емулятора.
* `GIT.md` — Конспект з інформацією про Git.
